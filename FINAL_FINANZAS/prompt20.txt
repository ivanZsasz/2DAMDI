=== 3. AJUSTES CON LOCALSTORAGE ===

Lista de toggles estilo iOS con persistencia local.

Opciones:
- Modo Oscuro: Añade clase .dark-mode al <body>
  - CSS invierte los colores principales
  - Estado guardado en localStorage('velut_darkMode')

- Notificaciones: Toggle visual
  - Estado guardado en localStorage('velut_notifications')

- Biometría (FaceID): Toggle visual
  - Estado guardado en localStorage('velut_biometrics')

Los toggles recuerdan su estado entre sesiones gracias a localStorage.

=== 4. GESTIÓN DE DATOS (Ficheros) ===

Sección "Privacidad y Datos" con exportación de backup.

Botón "📥 Exportar mis datos (JSON)":

Lógica de implementación:
1. Obtener todas las transacciones del usuario desde Firebase
2. Crear objeto JSON con estructura:
   {
     "exportDate": "2024-01-15",
     "user": { "email": "..." },
     "transactions": [...]
   }
3. Convertir a Blob de tipo application/json
4. Crear URL temporal con URL.createObjectURL()
5. Crear <a> dinámico con download="mis_finanzas_backup.json"
6. Simular click para forzar descarga
7. Revocar URL para liberar memoria

Esto cumple requisito académico de manipulación de ficheros locales.
