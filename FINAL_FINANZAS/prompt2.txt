Actúa como un Experto en Desarrollo Web Frontend y Diseñador UI/UX Senior. Quiero crear una PWA (Progressive Web App) de Finanzas Personales lista para ser empaquetada como APK.

Tecnologías:
Core: HTML5 Semántico, CSS3 Moderno (Variables, Flexbox, Grid), Javascript ES6+ (Vanilla, sin frameworks).
Backend as a Service: Firebase (v9+ modular).

1. Configuración de Firebase: Inicializa la app con este objeto de configuración (usa librerías CDN): [FIREBASE_CONFIG_USER_PROVIDED]

2. Sistema de Diseño UI/UX (Estilo 'Glassmorphism Clean' & Accesible): Quiero una interfaz minimalista pero visualmente impactante, apta para jóvenes y personas mayores.
Paleta: Fondo #F5F7FA, Tarjetas Blanco #FFFFFF, Acento Principal #4F46E5 (Índigo), Texto #1F2937.
Formas: Bordes muy redondeados (border-radius: 20px en tarjetas, 12px en botones). Sombras suaves (box-shadow) para dar profundidad.
Accesibilidad: Tipografía grande y clara ('Poppins' o 'Inter'). Botones con área táctil mínima de 44px. Contraste alto.
Layout: 'Mobile First'. En escritorio, centra el contenido en un contenedor tipo móvil o usa un grid de 2 columnas.

3. Requisitos Funcionales y Flujo:
A. Autenticación (Login/Registro):
Diseña una pantalla de bienvenida limpia y moderna.
Métodos: Email/Contraseña Y Botón "Continuar con Google" (usa GoogleAuthProvider de Firebase).
Maneja errores de forma visual y amigable.

B. Navegación (Bottom Navigation Bar):
Barra fija inferior flotante con 5 items: Inicio, Análisis, Botón Central Flotante (+), Noticias (API), Perfil.
El botón central (+) debe destacar (más grande, color acento, sombra).

C. Pantalla de Inicio (Dashboard):
Header: Muestra un saludo: 'Hola, [Nombre del Usuario]' en la esquina superior para confirmar identidad. A su lado, la foto de perfil (si viene de Google) o un avatar genérico.
Tarjeta de Balance: Un rectángulo con gradiente suave que simule una tarjeta de crédito. Muestra el saldo total y un icono de 'ojo' para ocultar/mostrar la cifra.
Lista de Movimientos: Debajo, lista las últimas transacciones. Usa iconos con fondos de colores pastel para las categorías (ej: icono comida sobre círculo naranja suave).

D. Añadir Transacción (UX Premium):
Al pulsar el botón (+), NO cambies de página. Despliega un Bottom Sheet (panel que sube desde abajo y ocupa el 50% de la pantalla) con fondo efecto vidrio (backdrop-filter: blur).
Input: Campo de monto gigante y claro.
Teclado Personalizado: Implementa un teclado numérico HTML (botones grandes en grid 3x4) dentro del modal para que sea fácil de pulsar para personas mayores. No uses el teclado nativo del móvil.
Permite subir foto del ticket (Firebase Storage).

E. Conexiones API:
En la pestaña 'Noticias' o 'Mercado', consume una API gratuita (ej: CoinGecko o ExchangeRate) para mostrar valores de divisas/cripto en tarjetas simples.

F. Funcionalidad PWA (Crítico para APK):
Genera un manifest.json completo (nombre: 'MiFinanza', short_name, iconos, theme_color: #4F46E5, display: standalone).
Genera un service-worker.js básico para que la app funcione offline y sea instalable.
