=== 1. BUG CRÍTICO DE LAYOUT ===

Problema identificado: El contenido de 'Mercado' se expande al 100% del viewport,
cubriendo el Sidebar de navegación. Esto ocurre porque el contenedor principal
no respeta el espacio reservado para la barra lateral.

Solución técnica:
- La clase .main-content debe tener un margin-left igual al ancho del sidebar (250px)
- Alternativamente, usar un layout Flexbox donde sidebar y contenido sean hermanos
- El sidebar debe tener position: fixed o sticky con z-index alto
- En mobile, el sidebar se oculta y el contenido ocupa el 100%

Media queries necesarias:
@media (min-width: 768px) {
    .main-content {
        margin-left: 250px; /* Width del sidebar */
    }
}
